# Закрывающий тег

Восемь карточек о пути в разработку: оригинальные пиксельные иллюстрации, CSS-фильтры, анимированные лайки и модальное окно сохранения. Использованы вариативный Inter и акцентный PressStart2P.

Репозиторий: https://github.com/petrtochilkin/zakrivayuschiy-teg-ad

Сайт: https://petrtochilkin.github.io/zakrivayuschiy-teg-ad/

Для локального просмотра откройте index.html или запустите HTTP-сервер.
